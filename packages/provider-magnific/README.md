# vinci-provider-magnific

First-class Magnific / Freepik HTTP plugin. Auth is the `x-magnific-api-key`
header (`MAGNIFIC_API_KEY`). This is not an MCP wrapper. Magnific also ships an
OAuth MCP server. Vinci also ships a sign-in connector, `mcp_magnific`, at
`https://mcp.magnific.com` (tools `images_generate`, `video_generate`,
`creation_status`). Docs: https://docs.magnific.com/introduction
