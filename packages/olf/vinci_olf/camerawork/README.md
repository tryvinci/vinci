# Camerawork library

Camera and staging templates for OLF shots, by namespace (`anime/`). A shot uses one through its
show's bible: `vinci olf template anime/tu-to-eyes --shot e02/s03/sh014` copies the file to
`bible/camerawork/tu-to-eyes/tu-to-eyes.yaml` and sets `camera.template: cam/tu-to-eyes`.

Universal (`LICENSE` in this folder, SPDX `CC0-1.0`). A show can copy them and change them with
no credit line. The rest of the `vinci-olf` package is Apache-2.0.

The format of a template: `SPEC.md`, Camerawork. The terms come from public glossaries of anime
production; the names, intents and prompt words are our own text.
