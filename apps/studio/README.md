# @tryvinci/studio

TypeScript Studio for the local Vinci daemon. One format-grouped rail (Explore, Image and Video flyouts, Canvas, Library, plus Skills, Find, Cost, Connect), All tools and Ctrl+K over those same entries, canvas (Magnific-style node cards, typed Text/Image/Video/Audio ports, click-output-to-add, add-node popover), cinema stack, and BYOK Connect live here. The Mac and Android apps load this Studio on `:4311`. The daemon HTML at `/studio` is a **deprecated** fallback: it is frozen, so new Studio work lands here only. The fallback rail matches these groups. A blank Canvas asks you to choose a first node.

Studio chrome is the Vinci site palette on a near-black field. Glass (`--glass-*`: blur 22px, saturate 140%, a 4–7% white fill, a hairline, a top highlight, a soft shadow) is the surface for the rail, top bar, side panels, prompt bar, canvas card controls, dock, inspector, Assets filters, and the Ctrl+K / All tools popovers. A faint neutral gradient sits behind the canvas and the feeds so the blur has something to sample. Teal stays on the primary action and the active mark. An idle canvas card shows the media, a title, and a muted subtitle; prompt, pills, and Run appear on hover or select. The dock is icon buttons. Ports are dots; the kind is a tooltip. Assets is the CAS library index (sections, type filters, date groups, trash), not a hash list. Image is a Higgsfield-style masonry feed of your stills plus a bottom-center prompt bar (`+` reference, `@` Elements, model picker, aspect, quality, resolution, batch 1/4, Generate with $). Video is a Higgsfield-style left panel (~220px) plus History feed (empty state is a three-card staged how-it-works strip): preset card + Change overlay, References | Extend Video, refs dropzone, prompt with @, audio chip, model row, Duration/Aspect/Quality tiles, Generate with $, Advanced steps/seed. Animate on an Image card opens Video with the still as the start frame. Speak, Upscale, Adapts, and catalog effects share the **Effects shell** (`EffectShell` + `lib/apps-catalog.ts`): preset-driven left panel, per-effect history on the right, **Change** opens the masonry gallery overlay (no Apps rail page). Library is Magnific tabs (Characters, Elements, Styles, Locations, Brand kit, Templates, Flows). Create is name + 1-8 images. A shared `MentionPopover` lists the same Characters / Elements / Styles / Locations when you type `@` on Image, Video, canvas nodes, and other prompt boxes. The chosen item's refs go on the provider request.

- Next.js app: `npm run dev --workspace @tryvinci/studio` on port `4311`
- API proxy: `/vinci-api/:path*` → daemon (runtime route handler; set `VINCI_DAEMON_URL` + `VINCI_BRIDGE_TOKEN` for Mac bundle). Dev may set `VINCI_STUDIO_USE_REWRITE=1` to use Next rewrites instead.
- Deprecated daemon page: `http://127.0.0.1:4310/studio`
- `./scripts/vinci studio` starts the daemon and this Studio on `:4311`. It falls back to `/studio`, with a warning, only when this Studio cannot start (or with `--html`).
- Local models run without a pasted key. Live HTTP needs a provider key **and** `VINCI_ALLOW_LIVE_SPEND=1`.
- Brand: `app/theme.css` (tokens), `app/brand.css` (shell, bars, cards, empty states), `app/ui/logo.tsx` (real Vinci mark). Tailwind utilities map to the same tokens. See `docs/VINCI_OSS_RUNTIME.md` section 10.
- Canvas selection, history, pages, and the minimap are floating glass layers (`app/canvas-chrome.tsx`, `lib/canvas-board.ts`). "Up to here" runs the selection and what feeds it and shows that cost before the run. Pages and comments persist in `vinci-canvas-project-v1`. Card Run still includes ancestors. Right-click keeps "Run this node only".
- Model lists come from `lib/model-capabilities.ts`. `modelsFor(surface, connectedProviders, models)` keeps compatible rows from connected providers. Mock is hidden once any other provider is connected. Image, Video, Effects (`appModelChoices`), the rail Models flyout, the add-node popover, and each canvas node pill use it. The Image and Video feeds request `/library` only when the daemon OpenAPI spec lists that route. Canvas model, aspect, and resolution controls are keyboard pills (arrows, Enter, Escape), the same shape as the prompt bar. Upscale still is still upscalers only; clip upscalers use `video_upscale`. There is no mapping screen.
